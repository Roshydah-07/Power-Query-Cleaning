# Power-Query-Cleaning
A self-learning project focused on cleaning and transforming a dental dataset using Microsoft Power Query.

### 📌 Project Overview

This project focuses on cleaning and transforming a dental dataset using Microsoft Power Query. The project was completed as part of my self-directed learning journey in Data Analytics.

The main goal was to take a raw dataset, identify data quality issues, apply appropriate transformations, and prepare the data for further analysis.

---

## 🎯 Project Objective

The objective of this project was to:

- Clean a raw dental dataset
- Identify and handle data quality issues
- Transform and standardize the dataset
- Prepare the data for analysis
- Gain practical experience using Microsoft Power Query

---

## 🗂️ Dataset

**Dataset:** Dental Dataset

The dataset contains information related to dental records and was used to practice real-world data cleaning and transformation techniques.

---

## 🛠️ Tools Used

- **Microsoft Power Query**
- **Microsoft Excel**

---

## 🧹 Data Cleaning & Transformation Process

I worked through the dataset in Power Query and applied several data preparation steps, including:

- Examining the structure and quality of the raw dataset
- Identifying inconsistencies in the data
- Cleaning and standardizing data
- Transforming columns where necessary
- Adjusting data types
- Removing unnecessary or irrelevant data
- Preparing the final dataset for analysis
